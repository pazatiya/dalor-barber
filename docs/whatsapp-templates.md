# תבניות WhatsApp להגשה ב-Meta

הגדרות לכל התבניות: **קטגוריה: Utility** · **שפה: עברית (he)** · סוג: Text בלבד (בלי כותרת/כפתורים).
משתנים: `{{1}}` שם · `{{2}}` מתי · `{{3}}` קישור. בשליחה אין שורות חדשות בתוך משתנה (הקוד מנקה).
Meta לא מאשרת משתנה בתחילת הטקסט או בסופו, ולכן כל תבנית מתחילה ונגמרת במילים.

## 1. dalor_booking_confirm  (משתנה סביבה: WA_TEMPLATE_CONFIRM)
```
שלום {{1}}, התור שלך במספרת DALOR נקבע ל{{2}}.
לניהול או ביטול התור: {{3}}
נתראה במספרה!
```
דוגמאות: {{1}}=דנה · {{2}}=יום ראשון, 7.1 בשעה 10:00 · {{3}}=https://dalorbook.duckdns.org/?b=ABC123&t=XYZ

## 2. dalor_booking_rem24  (WA_TEMPLATE_REM24)

```
שלום {{1}}, תזכורת: התור שלך במספרת DALOR מחר, {{2}}.
לניהול או ביטול התור: {{3}}
נתראה!
```

## 5. dalor_booking_cancel  (WA_TEMPLATE_CANCEL)
```
שלום {{1}}, התור שלך במספרת DALOR בוטל.
לקביעת תור חדש: {{2}}
נשמח לראות אותך בהמשך.
```

## הערות
- שמות התבניות באותיות קטנות ו-_ בלבד (דרישת Meta).
- אחרי האישור, להגדיר ב-Render: `WA_TEMPLATE_CONFIRM=dalor_booking_confirm` וכן הלאה.
- ל-`{{2}}` הקוד שולח טקסט כמו "יום ראשון, 7.1 בשעה 10:00" (ובהזמנה קבוצתית: "(2 אנשים)" בסוף).
